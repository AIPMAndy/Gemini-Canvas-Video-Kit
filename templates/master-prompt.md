# Gemini Canvas 完整视频总控提示词

你现在工作在 **Gemini 网页版的 Canvas** 中。请直接生成可运行的、单个完整 HTML 网页。不要给我策划案、分镜图片、静态 PPT、Markdown 说明或安装步骤。

目标：做一支【30】秒、【16:9】的完整网页动画宣传片。主题：【产品/话题】。目标观众：【观众】。唯一卖点：【卖点】。可证明的内容：【证据，如无则明确标为概念演示】。

**严格约束**：
1. HTML、CSS、JS 自包含；不调用 Gemini API、第三方 CDN、Node.js 或外部图片/音频，基础版本在浏览器预览中即可运行。
2. 按秒实现五个自动衔接的场景：0–3 秒钩子，3–7 秒痛点，7–19 秒完整模拟演示，19–26 秒结果，26–30 秒行动引导。根据实际信息微调但总时长必须准确。
3. 每个场景都有明确镜头构图、动态变化和字幕。对模拟产品 UI 做连续操作：点击 → 输入 → 加载 → 结果；不可用跳变页面冒充真实操作。
4. 输出一个播放画面和必要的控件：播放/暂停、从头重播、静音或声音说明、全屏。点击播放后能自动播到结束，所有状态重播时必须重置。
5. 视觉克制：留白、清晰的字体层级、真实感强的界面、字幕安全区，不要无意义粒子、渐变漂浮字、频繁缩放。
6. 不允许捏造真实用户、营收、效果统计或客户 Logo。虚构数据和 UI 必须显著写明“概念演示”。
7. 音频优先提供旁白脚本、按场景同步的字幕；如使用浏览器 `speechSynthesis`，要有用户主动点击开关，并写明语音可用性和录屏捕获不保证。绝不把它称为已同步的专业 TTS 音轨。
8. 代码生成完成后直接展示可交互预览。若有问题，先修镜头顺序、播放控制和文字遮挡，再修视觉效果。

**成片的定义**：我只需要在 Canvas 中打开这个页面，点击“从头播放”，全屏录制一次，即能得到没有手工点击推进的完整视频。
