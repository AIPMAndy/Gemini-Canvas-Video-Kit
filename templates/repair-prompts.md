# Gemini Canvas 二次修改 Prompt

每次选择一种问题，明确要求 **保留现有可工作内容，只修改指定问题**。避免整片推倒重做。

## 镜头不连续
请保留现有画面和数据，把各段动画归入统一秒级时间轴。点击一次「从头播放」后从 0 秒播到结尾，不得靠我点击页面推进；每段开头和结尾必须对应上段 UI 状态。检查暂停、拖动进度、重播时是否正确重置。

## UI 太假
请把当前模拟 UI 改成真实产品视觉逻辑：按钮点击 → 文本输入 → 状态等待 → 输出结果。画出自然鼠标轨迹与等待反馈，不要让整个页面瞬移或凭空出现结果。所有未由真实素材提供的产品事实保持「概念演示」标注。

## 字幕字体太像 AI 模板
全局删除无意义彩色描边、膨胀粗体、到处弹跳的标题。采用最多三层字级（主标题、说明、字幕），克制留白，字幕与主视觉分层，不遮挡按钮和结果。

## 节奏太慢
前 3 秒先说用户能得到什么。删除重复解释，把最重要的输入与结果演示放到中段，不要在“Logo 旋转”上浪费 5 秒。总时长保持不变，重算每个场景秒数。

## 录屏出现黑边/裁切
将舞台固定为目标宽高比（16:9 或 9:16），使用居中适配而不是把内容挤出边界。预留字幕与 UI 安全区，避免鼠标经过外部播放按钮区域。

## 配音不同步或未播出
不要声称已经合成音轨。把每场的逐句旁白稿和字幕完整显示，并标注建议起止时间；如浏览器朗读不稳定，默认关闭朗读，让画面仍可单独播放录制。

## 移动端预览太卡
移除大型阴影、过多模糊滤镜、实时粒子、外部 CDN 与巨量 DOM，保留简洁 CSS/SVG/Canvas 动画。减少每帧 DOM 更新量，检查低性能机器播放。
