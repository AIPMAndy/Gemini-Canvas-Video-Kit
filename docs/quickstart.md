# 五分钟入门：直接用 Gemini 网页版 Canvas 做完整视频

## 目标

只用 [Gemini 网页版](https://gemini.google.com/) 的 Canvas，不安装 CLI，不创建 API Key。将视频设计为**可自动播放的单页 HTML 动画**，通过屏幕录制得到最终文件。

## 步骤

1. 打开本仓库首页 `index.html`，选择「产品宣传片」「连续 UI Demo」「知识科普」等类型。
2. 输入核心卖点：**给谁看 → 看完获得什么 → 哪一步能证明。** 尽量用一句话说明，不堆三个卖点。
3. 选 15 / 30 / 45 / 60 秒和 16:9 / 9:16，点击「生成并复制提示词」。
4. 打开 Gemini 网页版，选择 **Canvas**，粘贴完整 Prompt。强调「直接生成可运行网页，不要解释，不要 Markdown 方案」。
5. 在预览中点播放。观察是否存在空白、镜头停顿、字幕遮挡、按钮失效、光标瞬移、数据不真实。
6. 把发现的问题复制给 Gemini，让它按 `templates/repair-prompts.md` 修改。每次只改一个优先级最高的问题。
7. 预览稳定后全屏，用系统自带屏幕录制录下从头到尾的一次完整播放。

## 质检底线

- 视频从 0 秒自动播放到结束，没有中途需要用户点按钮的步骤。
- 有连续操作证据：页面输入、反馈、结果的顺序合理。
- 内容不编造真实成交、客户名称、产品能力、测评结果。
- 全屏有稳定比例，重要文字不靠近裁切边界。
- 音频无法保证时，先完成带字幕画面，再单独处理旁白。

## 如何区分演示与事实

- **真实产品演示**：录制真实产品 UI/结果，并对敏感信息做遮挡。
- **概念 Demo**：代码模拟 UI，有代表性的效果展示，显著标注「概念演示 / Fictional UI」。
- **AI 生成画面**：不代表实际产品功能或测试证据。

本项目示例使用虚构的 FocusFlow 产品，专为展示制作方法，不得包装成实测产品。
