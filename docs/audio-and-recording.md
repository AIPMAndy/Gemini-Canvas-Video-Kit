# 音频与录屏：不要向用户承诺不存在的一键 MP4

## 首选交付

- **网页**：Canvas 直接生成，含定时镜头、字幕、自动模拟操作和控制栏。
- **录制**：使用设备系统录屏；例如 macOS 可用 Shift-Command-5，Windows 可用系统录屏或 OBS。是否能录到网页声音取决于系统、设备权限和录制方式。
- **旁白**：优先在分镜开始之前确定逐句脚本，再按系统可用的 TTS/后期配音方式制作。

## 浏览器语音的限制

`speechSynthesis` 可以在部分浏览器从用户点击开始朗读文字，但中文语音、速度、发音、可用声线、播放延迟和录屏是否收录都不保证。它不等于可验证的高品质 TTS 音轨。建议把文稿单独导出并用稳定的配音工具生成音频，再检查声画同步。

## 录屏前的检查

1. 选择一个稳定的浏览器窗口，关闭通知和聊天弹窗。
2. 检查屏幕录制是否捕获页面音频；先录 5 秒再回放确认。
3. 先让页面资源加载完毕，再点击视频「从头播放」。
4. 录制整个视频，结束后检查尾帧没有截断。
5. 若要发布到竖屏平台，请从一开始就选择 9:16，避免简单裁切横版。

## 不可夸大

- 不保证 Gemini 网页版支持把任何 HTML 页面直接导出成 MP4。
- 不保证 Canvas 预览环境放行所有 Web API（例如 `getDisplayMedia`, `MediaRecorder` 或全屏）。
- 不保证 `speechSynthesis` 与视频时间轴严格对齐。
- 需要写实生成镜头时应区分 Gemini/Veo 视频生成与 Canvas 代码动画，这不是同一种输出。
