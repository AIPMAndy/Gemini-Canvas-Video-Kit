# 能力边界与已知限制

## 确定的基础

Gemini 官方说明网页版 Canvas 可以从提示词生成可运行的网页/应用、预览代码动画，并可分享 Canvas 内容。因此本项目只依赖它的**网页代码生成与运行能力**；本项目不依赖 Gemini API、CLI 或插件安装。

## 不能保证的事

- 任何具体模型版本是否对所有用户开放、Canvas 是否能使用特定外部资源；不同账号和地区可能有差异。
- Canvas 内置直接输出 MP4、WebM 或完整有声视频文件。
- 浏览器 Web Speech 的音画同步、无字幕错位、收音成功。
- 生成的 UI 与真实产品 100% 一致——如需实录，请输入可靠的产品素材并人工核实。
- 任何提示词都能一次性达到商业成片质量。

## 当前状态

- `[可运行]` 本项目本地单页提示词生成器。
- `[可运行]` 两个独立 HTML 动画演示；示例 UI 为虚构。
- `[待独立验证]` 具体提示词在不同 Gemini Canvas 账号/模型上的生成质量与稳定性。
- `[未提供]` 直接从 Gemini Canvas 一键导出 MP4。
