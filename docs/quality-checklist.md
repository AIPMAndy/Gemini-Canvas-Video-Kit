# 十五项视频验收标准

打分：每项 0（不符合）/ 1（部分）/ 2（符合），满分 30；**24 分以上且全部红线过关**才适合发布。

| # | 检查项 | 红线 |
| - | - | - |
| 01 | 开头 3 秒明确问题或结果 | 是 |
| 02 | 全片只围绕一个核心价值 | 否 |
| 03 | 每个镜头有明确起止秒数 | 是 |
| 04 | 点击播放后可自动播完 | 是 |
| 05 | 文字与关键对象不出安全区 | 是 |
| 06 | 主标题不被字幕压住 | 是 |
| 07 | 模拟操作有连贯因果 | 是 |
| 08 | 鼠标轨迹不过分漂移 | 否 |
| 09 | 关键结果停留至少足够阅读 | 否 |
| 10 | 重要数据有真实来源或标注为示意 | 是 |
| 11 | 无空白页、白闪、资源加载失败 | 是 |
| 12 | 字幕与内容匹配，无错字 | 是 |
| 13 | 声音不互相掩盖，无突然爆音 | 如有音频 |
| 14 | 画幅在目标设备上完整可读 | 是 |
| 15 | 结尾有单一且清晰的 CTA | 否 |

**红线必须全部通过**；分数不是对真实商业转化率的预测。

## 质量迭代顺序

按照问题优先级修：①事实真实 → ②镜头连续 → ③节奏和音画 → ④字体字幕 → ⑤装饰特效。不要通过加粒子、光效或虚假 UI 掩盖真实产品的缺陷。
